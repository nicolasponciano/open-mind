# Orientações do Vault de exemplo

- Leia as notas relevantes antes de resumir ou relacionar informações.
- Preserve o sentido original ao organizar ou sugerir alterações.
- Prefira títulos claros e links Markdown do Obsidian (`[[Nota]]`) quando ajudarem na navegação.
- Não suponha que uma pasta ou convenção exista se ela não estiver presente.
- Peça confirmação antes de qualquer escrita; este exemplo não autoriza alterações.
